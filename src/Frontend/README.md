# Karamchari Frontend (Nx workspace)

This directory will host the Nx + Next.js + TypeScript workspace.

> **Status:** Not yet initialized. Day 1 is backend-foundation only.

When initializing, scaffold with:

```bash
npx create-nx-workspace@latest karamchari-fe \
  --preset=next \
  --appName=portal \
  --style=css \
  --packageManager=pnpm
```

Then move the generated files into this directory.
